## 3. Ключевые связки

**Смерть Адама:** дефект реален (но замены не было) + лист разорван наверху + Адам пытался связаться с Ричардом и поднимался + **время** (узел/радио/канал: сводка после удара) + **место** (слова Леи из кабинета: три прохода) + **предмет** (страниц печати нет в папке; папку собирала Эмма) + знание Адама (сеанс, печать) + мотив (сделка) + её ложь (L1–L4, L7) + знание о постановке (голос) → толчок Эммы — наиболее убедительная реконструкция. Умысла на смерть нет; дефект участвовал.

**Эмма:** протокол (сводка, «стучала», «собрала», направляет правдой) ↔ журнал узла (коды) ↔ почта (питомец) ↔ печать ↔ журнал канала ↔ радио ↔ Лея ↔ диктофон/репетиция.

**Ник:** половины листа ↔ FieldWorks ↔ ноутбук/E05 → шантаж; радио снимает; отказ Мике; ночные шаги.

**Лея/Кейт:** одинаковые слова ↔ журнал Кейт ↔ ключ ↔ Том (анкета, копия) → Лея в кабинете → её «лишнее знание» = правда о коридоре.

**Габриэль:** телефон в кабинете ↔ заявка «не передано» ↔ отказ ↔ последнее голосовое; ложные следы: ночная попытка у узла (Мики), испанский телефон у «переводчицы».

**Мика:** протокол «переводчица» ↔ Габриэль/испанский ↔ книга ↔ заметка ↔ блокнот ↔ диктофон ↔ журнал двери ↔ протокол Дэна (нашёл, передал) ↔ Адам «доложу» → ложная утечка → утром Адам смотрел сеанс Эммы.

**Компания:** вызов → обработка/блокировка → транспорт ↔ внешняя дата; «Кейт — рука Ричарда» умирает в Томе и обработке. **Постановка:** репетиция + живая запись + «этап C» + данные Ричарда. **Испытание:** C-A (6 строк) + таблица Мики + «выдача после УТ» + A22 + этапы.

**Том:** Лея → Мика (семя) → официальная версия → анкета → выдача Y → копия (у Леи с ночи 12/13; происхождение — Кейт) → подлог; этап A.

## Замки и барьеры

Замки (три): питомец → почта Эммы (M12); старая эмблема → ноутбук (M21); ключ-файл Ричарда → X-17 (M22). Новая предметная операция: сопоставить идентификаторы пакетов в журнале узла с журналом экспорта данных программы. Шкала времени: три часа (журнал узла, радио, журнал канала) сверяются по объявлению тревоги, которое есть на радиозаписи и в журнале сервера. Всё остальное — барьеры понимания: коды пользователей в журналах; испанский на телефоне; голоса (диктофон ↔ вводные интервью ↔ эфир ↔ репетиция); «лишнее знание»; одинаковые формулировки; «чего нет» в папке; фото «после» не той лестницы; два устройства — два владельца; автор снаружи = внутри.

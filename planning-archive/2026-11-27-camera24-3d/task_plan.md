## Decisions Made
| Решение | Причина |
|---|---|
| SN-3 (Sony W210/W220), без ремешка | выбор автора 27.11 |
| Объектив убран | в режиме просмотра у таких камер он не выезжает; игрок только смотрит кадры |
| Гладкая геометрия сразу, фото-текстуры с износом, без грязи внутри кнопок | уроки телефона 48 (замечания автора) |
| Картинки — группами по темам | правило автора 27.11 (память `send-variants-separately`) |
| Металл, белый свет, меньше износа | замечания автора ко второй пробе (ART-75) |
| Ярлык на стороне объектива, бумага с фактурой, без залома | замечания автора к пробам 3–5 (ART-76) |

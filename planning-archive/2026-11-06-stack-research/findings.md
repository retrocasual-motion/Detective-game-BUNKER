# Findings: исследование стека

## Требования из TECH_PLAN v2 (критерии)
- Браузер, десктоп, 1366×768+; стол ~150–300 объектов + доска; полноэкранный просмотр с выделением текста; 6 3D-предметов; плеер с шкалой; радиозапись 15 суток (шкала событий + фон); устройства-эмуляции; виды комнаты (кадры+переходы).
- Сервер обязателен (P-10: правила, пароли, рубрика на сервере); задержанные письма; сессии; журнал действий; каналы доставки (почта/телефон/сайты).
- Аудитория — Россия (российские номера S-4, русский язык): хостинг, почта, оплата, телефония должны работать в РФ; 152-ФЗ — персональные данные россиян (email) хранить в БД в России.

## Найдено (06.11)
- tldraw SDK: коммерческое использование — платная лицензия (официально «contact sales»; сторонние — ~$6k/год, не подтверждено) → не берём.
- PixiJS: WebGL, тянет десятки тысяч карточек; Konva — Canvas 2D; для 150–300 объектов хватает DOM + CSS transform, а текст выделяется нативно.
- Cloudflare в РФ замедлен с 09.06.2025 (16 КБ), на ноябрь 2026 не снято → не использовать Cloudflare CDN/Pages для игры и сайтов.
- 152-ФЗ: локализация БД с персональными данными россиян в РФ (ч. 5 ст. 18); штрафы выросли с 30.05.2025.
- Yandex Cloud Postbox: первые 2000 писем в месяц бесплатно; SMTP/AWS SDK.
- Voximplant: сценарии IVR на JS, Web SDK (звонок из браузера через WebRTC) — один сценарий для номера и браузера; цены номеров — уточнять.

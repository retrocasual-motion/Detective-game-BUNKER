# Findings: пакет игрока v1

## Формат (playtest.py, player-pack-spec)
- Пакет: `playtest/packs/<версия>/` PACK.md, player/ (копируется игроку), locked/ L<NN>__*.md (по правилам), gm/ (access.json, forbidden-terms.txt, lint-allow.txt, sources.md).
- Действия скрипта: ПАРОЛЬ (точное, без архивариуса), ЗАПРОС и ПОИСК (regex + архивариус по intent/required), ФИНАЛ, СТОП. Список захардкожен в ACTIONS и lint.
- Правило без intent — только regex. Архивариус берёт пул = кандидаты по цели, иначе все правила этого действия с intent.
- Если hit, но файлы уже выданы → ответ `again`. release [] → тоже `again` (можно использовать как текстовый ответ без файла).
- lint HARD: \b[EFRN]\d{2}\b, \bA\d{2}\b (A-24 с дефисом НЕ ловит), M\d{2}, CA-\d{2}, «ложн след», спойлер, канон, авторск, плейтест, ссылки на файлы сводов. WARN: игрок (кроме 00_), убийц, разгадк/подсказк, улик, S0–S4, Turn.
- PACK.md: approved-by-author: yes ставит только Artem; init без него не запустится.
- Профили есть: casual, completionist, experienced, speedrunner, skeptic.

## Решения по устройству (Phase 1 → 2)

### Расширение playtest.py (обратно совместимо)
- Новые действия: АДРЕС (`АДРЕС | браузер | <адрес>`), ЗВОНОК (`ЗВОНОК | <номер> | <что вводите>`),
  ОСМОТР (`ОСМОТР | <материал> | увеличить/свойства/листать/совместить`). Без архивариуса.
- release [] → ответ `ok`, в журнале «ответ» (сейчас — `again`/«повтор»).
- Поле `requires` (префиксы, уже выданные) + `requires_reply`: пароль почты — только после
  контейнера выгрузки; пароль архива — только после контейнера архива.
- lint проверяет новые действия и префиксы `requires`.
- player-brief.md: доп. действия — если описаны во вводной.
- Офлайн-тест прохождения: детерминированная симуляция по access.json без claude;
  доказывает достижимость всех locked и удержание ворот.

### Интерфейс (00_ВВОДНАЯ)
- Чтение case/ свободно; Grep игрока по case/ = «поиск по документам». ПОИСК по умолчанию:
  поисковика в интернете нет.
- Письма = ЗАПРОС на адрес. ПАРОЛЬ = любое поле ввода (пароль, PIN, графический ключ как
  последовательность клеток, дата архива газеты).
- ФИНАЛ = заключение для бюро: 4 пункта (кто / умысел / компания / дефект) + основания.
  C-2 открыт — пометить.

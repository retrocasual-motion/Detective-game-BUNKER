# Протоколы режимов аудита

Во всех режимах: опора — только то, что реально есть в сводах и доступно игроку
(02 «Где/Доступ», 03 §10 старт). Авторская истина (01) используется, чтобы знать
ответ, но не как опора игрока.

## A. Speedrunner

Цель: самый ранний момент, когда опытный игрок может получить **чрезмерную**
уверенность в правильном подозреваемом (чрезмерная = выше, чем позволяют его
материалы по стандарту 03 §7).

1. Возьми стартовый слой (03 §10 S0–S4) и всё, что открывается без замков
   (02 доступы A, «В деле сразу»).
2. Ищи:
   - слишком сильные ранние материалы (один носитель почти называет ответ);
   - уникальный мотив (только у одного персонажа есть причина);
   - непропорциональный объём материала про одного персонажа или «тихий»
     персонаж, к которому ведут все стрелки;
   - сочетание 2–3 ранних документов, которое сразу даёт решение;
   - мета-подсказки автора: необычно подробный протокол, странная пустота,
     материал без собственной функции (видно, что «положен для игрока»),
     нумерация/названия файлов, расположение в описи;
   - эффект «самый незаметный — значит, убийца» у опытного игрока.
3. Построй кратчайший путь: минимальный набор материалов → какую уверенность он
   даёт честно и какую даёт опытному игроку по жанровым паттернам.
4. Сверь с принятой позицией проекта: ранняя правильная догадка допустима,
   **доказать её одной линией нельзя** (HYP-03, 03 §5). Проблема — не ранняя
   догадка, а ранняя уверенность, которой не нужен остальной архив.

Таблица:

| Шаг | Материалы (ID) | Честная уверенность | Уверенность опытного игрока | Почему | Что ещё нужно для доказательства |
|---|---|---|---|---|---|

Итог: самый ранний шаг, где опытный игрок может превысить ~50% и ~80% на
правильном подозреваемом, и что именно его туда приводит. Пометка: прогноз
аудитора, не результат playtest.

## B. Skeptic

Предположи, что официальное решение неверно или недостаточно доказано.

Для подозреваемого по официальному решению отдельно:

| Элемент | Опоры (F/E) | Происхождение | Тип: прямое / косвенное / показание / вывод | Что игрок видит сам | Допущение автора |
|---|---|---|---|---|---|
| Мотив | | | | | |
| Средства | | | | | |
| Возможность | | | | | |
| Действие | | | | | |
| Намерение (если важно для финала) | | | | | |

Проверки:
- сколько независимых происхождений реально у каждого элемента (CLU-03);
  копии и пересказ одного источника — одно происхождение;
- выполняется ли стандарт E16 v3 (02, 03 §7) именно на доступном игроку;
- где авторская реконструкция подменяет факт («наиболее убедительно» → «доказано»);
- где цепочка держится на одном показании или одной интерпретации;
- что «положительно снимает» альтернативы и не является ли снятие отсутствием
  доказательств.

Итог: доказано / наиболее убедительно с оговоркой / не доказано; слабейшее звено.

## C. Alternative suspect

Для каждого значимого персонажа, кроме официального решения (состав — 01 §10):

1. Построй **лучшее** обвинение, используя только реальные материалы и сведения
   (E/F), доступные игроку. Не выдумывай улик.
2. Найди, что его **положительно** снимает и доступно ли это игроку до финала.
3. Оцени силу против официальной версии.

| Персонаж | Мотив | Средства | Возможность | Опоры (ID) | Что снимает (ID) | Снятие доступно? | Сила vs официальной |
|---|---|---|---|---|---|---|---|

Сила: слабее / сопоставима / сильнее. «Сопоставима» и «сильнее» — минимум S2.
Отдельно отметь главный ложный след (по сводам): работает ли он как ложный след,
а не как равноправная разгадка; что произойдёт с игроком, который закроет дело на
нём (форма финала C-2 — 04 §2).

## D. Continuity attacker

Ищи:
- невозможные маршруты и время (план v3, длины, время прохода; WORLD-03);
- временные противоречия между хронологией 01 и носителями (радио, журналы,
  подтверждения, CCTV, диктофон);
- носитель фиксирует то, чего не может (угол обзора, длительность, звук);
- персонаж знает то, чего знать не может (01 §9 «что каждый знал»);
- документ, созданный раньше события, которое описывает, или переживший то, что
  должно было его уничтожить;
- несостыковки алиби и показаний, которых автор не заметил (а не задуманная ложь:
  сверить с 01 и файлом линии, что ложь задумана);
- физически невозможные действия;
- остатки отменённых версий (v2) в 01–04, AGENTS, docs.

Каждая находка: два места сводов, которые противоречат, с цитатой.

## E. Fair play

- Все ли факты, нужные для решения, доступны игроку до финала (FAIR-01)?
  Пройди опоры центрального вывода (03 §8) и для каждой — где и как получена.
- Нет ли deus ex machina: факт, который впервые появляется в финальном
  объяснении или в эпилоге.
- Не требует ли решение знания, которого игрок не мог получить (внешняя
  профессия, редкое слово, угадывание формулировки; FAIR-03, CA-03).
- Можно ли логически прийти к ответу до reveal своими словами (DVC D).
- Обязательные улики, которые легко пропустить без альтернативного пути
  (GATE-02/03, CA-06, прогоны 03 §9): что теряется — глубина, опора или финал.
- Замки: условие доступа получаемо раньше зависимого результата; нет круга.
- genre-craft `mystery-fair-play.md`: «Mystery audit» с переводом глав на стадии
  доступа (skill-map).

## F. Пакет игрока (перед playtest)

Предмет: `playtest/packs/<версия>/` (формат —
`.claude/skills/detective-playtester/references/player-pack-spec.md`).

- Утечки: авторские ID (E/F/R/A/N/M, A-номера), слова «улика», «ложный след»,
  «игрок», «канон», интерпретации («это доказывает…») внутри материалов.
- Выделенность: описание фото/аудио/видео перечисляет нужную деталь первой,
  подробнее или иначе, чем остальные; у важного материала заметно лучшее
  описание. Это подсказка, которой нет в настоящем носителе.
- Полнота: всё, что игрок видит в настоящей игре на этой стадии, есть в пакете;
  нет материалов, которых в игре не будет.
- Правила доступа (`gm/access.json`): соответствуют принятым замкам и доступам;
  ответ интерфейса не подсказывает больше, чем настоящий интерфейс (CA-10).
- Запусти `python3 .claude/skills/detective-playtester/scripts/playtest.py lint --pack <путь>`
  и приложи вывод.

Итог: пакет пригоден / пригоден после правок (список) / не пригоден.

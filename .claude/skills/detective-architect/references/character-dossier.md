# Детективное досье персонажа

Дополняет `character-management/references/character-template.md` (внешность,
голос, арка — там). Здесь — то, что делает персонажа частью расследования.
Персонаж не существует отдельно от detective logic.

Досье — рабочий инструмент. В канон (01 §10, файл линии) переносится только то,
что автор принял.

## Поля

| Поле | Вопрос |
|---|---|
| Публичная роль | Кем он заявлен в программе и в деле? |
| Личная цель | Чего он хочет на самом деле в эти дни? |
| Страх | Чего боится потерять / что не должно выйти наружу? |
| Прошлое | Что из прошлого объясняет цель, страх, знания? |
| Отношения | С кем связан, кому должен, кого боится, кого прикрывает? |
| Секрет | Что за тайна; кто ещё её знает? |
| Что скрывает в деле | Какие факты прячет от следствия (и значит — от игрока)? |
| Почему врёт | Мотив лжи: своя тайна, чужая тайна, страх, выгода? |
| О чём именно врёт | Конкретные утверждения в показаниях, которые ложны или неполны |
| Что знает | На каждый ключевой момент: что знал (01 §9) |
| Чего не знает | Чтобы не протекало авторское знание в его поступки и показания |
| Где в ключевые моменты | Позиции по хронологии дня 13 и ночи 12/13, с точностью и опорой |
| Что делает | Действия в ключевые моменты, по его интересам |
| Какие следы оставляет | Носители: кто записал, почему сохранилось, как попало в дело |
| Улики на него | Материалы, которые указывают на него (E/F) |
| Невиновные объяснения | Для каждой улики на него: что на самом деле это значит |
| Функция в расследовании | Подозреваемый / ложный след / свидетель-опора / проводник к ветке / углубление; какой вывод R без него недостижим |

## Проверки досье

- Каждое действие объясняется **его** интересом, а не нуждой сюжета (SUS-01, DVC B).
- У каждого знания есть источник и момент получения (WORLD-01).
- Каждая ложь проверяема игроком хотя бы одной опорой; иначе это не загадка, а тупик.
- Ложь и тайна не делают его автоматически виновным, объяснённая тайна не даёт
  алиби (SUS-03).
- Если персонаж — ложный след: выполнены пять условий ложного следа
  (`mechanism-model.md`).
- Не растёт ли объём материала про него непропорционально его функции (сигнал для
  speedrunner-аудита).
- Состав — девять персонажей; десятого не добавлять (A-91), если автор не решит иначе.

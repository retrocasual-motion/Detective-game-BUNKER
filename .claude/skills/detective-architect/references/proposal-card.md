# Карточка предложения

Файл `claude/proposals/ГГГГ-ММ-ДД_<тема>.md` рядом со сводами. Статус всегда
«предложено», пока автор не выбрал. Это рабочий файл, не канон.

Разделы разделены намеренно: detective-auditor читает только «Что меняется»,
чтобы проверять само изменение, а не доводы его автора.

```
# Предложение: <тема> — <дата>
Статус: предложено · Автор предложения: detective-architect · Решение автора: —

## Что меняется
<!-- Только факты изменения, без оценок и доводов «за». -->
Вариант(ы): <метка> — <одна фраза>
Затронутые разделы сводов: 01 §…, 02 E…/F…/R…, 03 §…, 04 …
Новые/изменённые материалы: <паспорт: автор, время, причина, сохранность, путь в дело>
Опыт игрока: что видит → подозревает → ищет → действие → открывает → куда идёт
Изменения хронологии, знаний персонажей, доступов: …

## Почему так
Рекомендация, оценка (работает / с оговоркой / не работает), DVC, impact check,
рассмотренные и отклонённые варианты с причинами.
```

# Карточка улики и ложного следа

Для новой или изменяемой важной улики. Карточка — рабочая запись, не текст
материала. В 02 переносится после решения автора, в формате E/F/R/A.

## Поля улики

| Поле | Вопрос |
|---|---|
| Источник | Какой персонаж/процесс её породил (цепочка из `mechanism-model.md`) |
| Происхождение | Физическое или логическое: как возник след |
| Время появления | Когда создан носитель; когда след возник в мире |
| Паспорт | автор · время · причина создания · сохранность · путь в дело |
| Что буквально видит игрок | Поверхность без интерпретации: что видно сразу, что — действием (CA-01 О/Д/И) |
| Операция игрока | Что он делает: прочитать, сопоставить, рассмотреть деталь, соотнести звук и время, восстановить маршрут, собрать, найти отсутствующее |
| Первая интерпретация | Что игрок подумает при первой встрече |
| Настоящее значение | Что это на самом деле (сведение F → вывод R) |
| Поддерживает версии | Какие версии игрока укрепляет |
| Ослабляет версии | Какие версии подрывает |
| Персонажи | К кому относится (прямо / косвенно) |
| Раскрытие смысла | Когда и через что игрок понимает настоящее значение |
| Payoff | Нужен ли; какой вывод его закрывает |
| Независимость | Какое происхождение добавляет к выводу; не повторяет ли существующую опору |
| Режим доступности | Сразу / после нахождения / защищён — чем и почему в мире (CA-07) |

## Проверки улики

- Самообъяснимая улика не попадается раньше вопроса, на который отвечает (HYP-04);
  улика, требующая второго факта, может лежать где угодно.
- Предпосылки доступа лежат вне закрытого ею же материала (CA-05); нет круга.
- Пропуск этой улики: что теряется — глубина, опора или вся возможность закончить
  (GATE-02/03, CA-06). Если обязательная и единственная — обосновать или дать
  резерв (резерв ≠ новое доказательство).
- Не делает центральный вывод тривиальным одним сообщением (DVC H).
- Не требует внешних профессиональных знаний или редкого слова (FAIR-03, CA-03).
- Медиа: игрок что-то делает с носителем; есть причина существования носителя.

## Ложный след — дополнительно

| Поле | Вопрос |
|---|---|
| Чей реальный поступок | Какое действие персонажа в его интересах породило след |
| Почему правдоподобен | Какой разумный игрок и на каком шаге его заподозрит |
| Своя причина носителя | Зачем этот материал существовал бы и без обмана |
| Невиновное объяснение | Что на самом деле произошло |
| Чему учит разрешение | Какой верный факт о деле игрок получает, снимая подозрение (SUS-02) |
| Положительное снятие | Какая опора снимает версию (не «отсутствие доказательств») |
| Сила | Не становится ли ложный след сильнее настоящей версии; где игрок может на нём застрять навсегда |

Ложный след, который существует только ради обмана игрока, не предлагается.

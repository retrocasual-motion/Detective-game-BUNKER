## Как начать в новом проекте

1. Распакуй весь ZIP в отдельную папку и открой эту папку в Codex.
2. Передай модели полный текст `05_CODEX_START_PROMPT.txt`.
3. Попроси выполнить первую задачу: прочитать пакет и независимо проверить архитектуру расследования v3 (в первую очередь — согласованность 01–04 с `LEYA_LINE_FINAL.md` и остатки v2).
4. Обсуди найденные проблемы и варианты. Модель не должна сама утверждать изменения канона или согласованных способов получения.

## Приоритет и статусы

Текущие указания автора → явно принятые последние решения → своды 01–04 → `LEYA_LINE_FINAL.md` → более старые исходники. Методология задаётся двумя файлами в `docs/`; своды истории не отменяют методологию, а методология не разрешает самовольно менять историю.

В сводах различаются: **утверждено**, **направление принято / детали позже**, **предложено**, **не выбрано**, **отвергнуто / заменено**, **условный пример**. «Архитектура согласована» не означает «изготовлено» или «проверено плейтестом».

## Главное в v3 (для быстрого входа)

- Три замка — все на знании, ключей-файлов и хабов нет: питомец → почта Эммы; старая эмблема HEXON (угол знака на стёртой инвентарной наклейке на дне ноутбука + старый фильм на сайте HEXON; A-283; адрес сайта — с медлиста A-24) → ноутбук Адама; номер активной партии (0417) → архив проекта. Порядок «почта/ноутбук → архив» — осознанное исключение (A-190); с A-272 запросов нет: дверь архива — хранилище Ричарда по адресу из учёта офиса, название — из найденного материала. Мягкая задержка (не замок): PIN телефона Габриэля — из ролика-знакомства VAULTLINE (A-158, A-164).
- Четыре ключевых контейнера: почта Эммы; ноутбук; архив проекта (бумаги офиса); пакеты экспорта (читаемые копии в экспорте сервера).
- Лея доказывается только через чужие линии: узел (Эмма), таблица/канал/Мика (Кейт), пакеты/архив (Том), учёт офиса (родство). Одной её линией — «назвать может, доказать нет».
- Никто из следствия не перемещал улики: у каждого носителя — автор, время, причина, сохранность, путь в дело.

## Исходники и полнота

В `archive/original_project/` — 16 файлов проектной папки на момент сборки v1; в `archive/early/` — 10 ранних материалов. Они нужны для деталей и происхождения, не для возврата отменённого канона.

В архиве нет изготовленного комплекта игровых материалов, работающего терминала, готовых аудио/видео или результатов настоящего плейтеста. Картинки планов и схема лестницы — рабочие, не окончательные улики. Полного дословного экспорта всех прошлых чатов нет: обсуждения сохранены по смыслу в `DECISIONS_LOG.md`, `*_SESSION.md` и файле 04.

Оригиналы не менялись. Этот пакет — отдельная копия для продолжения работы.

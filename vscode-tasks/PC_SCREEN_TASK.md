## Два правила для всего задания (ART-94)
1. **Всё видимое работает.** Каждая кнопка, вкладка, значок, заголовок колонки что-то делает. Чего не делаем — не
   рисуем: без строк меню «Файл / Правка / Вид / Справка», без «Создать / Ответить / Переслать / Печать», без пустых
   папок; путь в окне — простой строкой, не поле ввода.
2. **Подсказки по управлению — отдельно от текста и улик:** мельче (≈11 px), темнее, другим шрифтом (не тем, что
   данные), строкой справа внизу окна; только важные; иконки мыши (ЛКМ, колесо) и клавиш вместо слов. Правило — для
   всей игры (§11 п. 15). Образец — `S19_SV-C3.png`, `S19_SV-D3.png`.

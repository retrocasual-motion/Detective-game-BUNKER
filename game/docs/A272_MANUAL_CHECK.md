# A-272: что проверить руками

Для автора. Ветка `dev/a272-entrances`. Список пополняется после каждого этапа. Отметки и
замечания можно писать прямо здесь или в чат, по номерам пунктов.

## Как запустить

1. В папке `game/` — `pnpm dev`; игра — http://localhost:5173.
2. Главное меню → «Новое дело» (прежнее дело на компьютере сбросится — это нормально).
3. Экран ~1366×768 или больше.

## Этап 2: запросов нет

- [ ] 2.1 В левом нижнем углу нет папки запроса; у правого края стола нет корзины.
- [ ] 2.2 Меню → «Настройки»: пункта «Ответы на запросы приходят…» нет.
- [ ] 2.3 Компьютер следователя (щелчок по монитору): на рабочем столе нет «Поступлений»;
      без диска — только «Браузер».
- [ ] 2.4 «Решить дело» → «Продолжить» → форма заключения: в вопросе о материале выделить
      строку в любом листе → кнопка «В заключение» кладёт карточку в форму; «В заключение
      целиком» у листа — тоже. Пока форма закрыта, этих кнопок нет. (Форма закрывает
      расследование — проверять в конце или на отдельном «Новом деле».)
- [ ] 2.5 Вход по ссылке на почту и письмо бюро новому игроку работают как раньше.

## Этап 3: лимит неверных вводов

- [ ] 3.1 Телефон (48): три неверных PIN подряд → поле ждёт ~2 минуты с отсчётом.
- [ ] 3.2 Ноутбук (47): три неверных ключа → то же.
- [ ] 3.3 Компьютер → «Браузер» → архив номеров газеты: десять неверных дат → пауза 2 минуты.

## Этап 4: диск сервера

- [ ] 4.1 На столе, у клавиатуры, — подсвеченный конверт «Прил. 7 · Сервер VL-31»; на стене
      его нет.
- [ ] 4.2 Щелчок → конверт в руках (крутится мышью), внизу «Вскрыть конверт».
- [ ] 4.3 «Вскрыть конверт» → в руках диск: крутится, надпись читается, обратная сторона —
      серебро. Кнопки «Вставить» нет.
- [ ] 4.4 Под монитором — тонкий дисковод CD/DVD (щель, кнопка, огонёк); системного блока не
      видно (он под столом). Щелчок по дисководу или монитору — компьютер.
- [ ] 4.4a Отложить диск (Esc или ✕) → диск лежит на столе на месте конверта, подсвечен.
      Щелчок по нему — снова в руки. Зажать и тащить — под курсором диск; отпустить мимо
      дисковода — ничего.
- [ ] 4.4b Дотащить диск до дисковода и отпустить → прямо на столе: лоток выезжает, диск
      ложится, лоток уезжает, огонёк мигает, звук раскрутки → открывается компьютер на весь
      экран (без дисковода в кадре) со значком «Сервер объекта VL-31». Нравится ли вид, движение
      и звук? Не слишком ли трудно догадаться, что диск надо тащить?
- [ ] 4.4c Вынуть диск, не вставлять, перезагрузить страницу — диск так и лежит на столе.
- [ ] 4.5 После вставки диска на столе нет ни конверта, ни диска; после перезагрузки — так же,
      значок программы на месте.
- [ ] 4.6 Программа: серый экран, «Время — часы сервера объекта. Только чтение.», меню из
      четырёх разделов.
- [ ] 4.7 «Журнал событий 13.10»: фильтр «Учётная запись: 05» — только строки с 05;
      «Сбросить»; щелчок по «узел связи» в строке — фильтр по терминалу. «Состояние на
      00:00» раскрывается; внизу «Пометка бюро».
- [ ] 4.8 «Узел связи за заезд» и «Терминал технической…» читаются, таблицы не налезают.
- [ ] 4.9 «Сеансы пользователей»: 07 → «Такого кода нет.»; 02 → «Сохранённых файлов… нет»;
      05 → учётная запись, история, входы и папка «Экспорты» (три файла открываются).
- [ ] 4.10 Три неверных кода подряд → поле ждёт ~2 минуты.
- [ ] 4.11 Журналы, сеанс и экспорты не появляются ни во «Входящих», ни на стене.

## Этап 5: сайты

Сайты открываются в Chrome по адресам вида `http://vaultline-program.localhost:5173` — их
отдаёт сервер игры на этом компьютере; в сеть ничего не выходит.

- [ ] 5.1 Стена → лист 02 (сопроводительное письмо): адрес `vaultline-program.com` — синяя
      ссылка. Щелчок → новая вкладка с сайтом VAULTLINE; лист в игре остаётся открытым.
- [ ] 5.2 Сайт: шапка, разделы, «Вход для сотрудников» с полями. В адресной строке нет
      длинного «?enter=…» — пропуск из игры убран.
- [ ] 5.3 Вход: `k.walsh` + неверный пароль → «Неверный логин или пароль.»; «Забыли пароль?» →
      логин `k.walsh` → «любимый герой».
- [ ] 5.4 Вход `k.walsh` / `Йен` → «Кабинет сотрудника»: «Учёт анкет» и «Документы программы».
- [ ] 5.5 Учёт анкет: только `A-24` → подсказка про дату выбытия; `A-24` + `06.10.2008` →
      ниже «Открытые документы» — анкета A-24. Программа `VL-31` → учёт текущего этапа.
- [ ] 5.6 Документы программы: несколько неверных названий подряд — поле не блокируется;
      `архив проекта` → ответ с адресом `docs.hexon-bio.com/vl-31` — ссылкой.
- [ ] 5.7 Щелчок по адресу хранилища → вкладка «Хранилище документов HEXON BIO»; пароль
      `0418` → «Неверный пароль.»; `0417` → три документа архива.
- [ ] 5.8 Хранилище до входа в кабинет (новое дело, адрес набрать в браузере компьютера
      следователя) → «Страница не найдена (404)».
- [ ] 5.9 Компьютер следователя → «Браузер» → в адресную строку `mailbridge.net` → «Переход»:
      сайт почты в новой вкладке, в игре — «Сайт открывается в новой вкладке браузера».
- [ ] 5.10 Почта: «Забыли пароль?» → `e.pierce.uk@mailbridge.net` → «Кличка вашей первой
      собаки?» → `Тоффи` → веб-почта: «Входящие» (8) и «Отправленные» (2), письма читаются,
      писать нельзя.
- [ ] 5.11 Банк `frontrange-savings.com` (набрать в браузере компьютера следователя):
      в разделе «Сейфовые ячейки» — форма «Сообщить о смерти арендатора». Без даты → «Ячейка с
      такими данными не найдена»; `845` / `Коул` / `13.10.2009` → «Сообщение принято…».
      (Коробка на столе — этап 6.)
- [ ] 5.12 Три неверных пароля на любом сайте → «Слишком много попыток. Повторите через…».
- [ ] 5.13 hexon-bio.com: раздел «Архив и медиа» — плеер со старым фильмом.
- [ ] 5.14 Вернуться во вкладку игры: сайты не появились ни во «Входящих», ни на стене;
      «Поиск» по фразе с сайта («Месяц тишины») ничего не находит.
- [ ] 5.15 Скопировать адрес сайта из вкладки и открыть в окне инкогнито → «Сайт дела
      открывается из игры…» без текста и форм.
- [ ] 5.16 Вид сайтов — функциональный (одна схема на все): устраивает ли как основа?

## Этап 6: коробка банка, кассета, проигрыватель

- [ ] 6.1 После верной формы банка (5.11) вернуться во вкладку игры: на столе справа, у лампы, —
      подсвеченная коробка «Ячейка № 845». Записки «Поступило во «Входящие»» нет, в лотке пусто:
      всё в коробке.
- [ ] 6.2 Щелчок → коробка в руках: «Front Range Savings · Ячейка № 845 · вскрыта 17.11.2009»,
      на крышке опись (L460, L461, L462). Сорвать пломбу → опись и лист — на стену группой.
- [ ] 6.3 На стене: лист акта (L461) — поперёк середины виден сгиб; в руках — тоже.
- [ ] 6.4 На столе, за ноутбуком, — проигрыватель с кассетой («Кассета · L462»). Щелчок → в
      руках проигрыватель с биркой бюро и кассета в футляре «06.10.08»; внизу «Вставить кассету
      в проигрыватель».
- [ ] 6.5 «Вставить…» → плеер записи 0:36: играть, назад, вперёд, шкала. Под шкалой — строка
      записи по времени (звука пока нет; субтитры для звука — на этапе дизайна звука). Бумажной
      расшифровки нет.
- [ ] 6.6 Нравится ли вид коробки, проигрывателя и кассеты (серый прототип 3D)?

## Этап 7: выписки на стену

- [ ] 7.1 На сайте (любом) выделить несколько слов мышью → у конца выделения кнопка «На стену»
      → внизу «На стене в деле — вернитесь к игре».
- [ ] 7.2 Вернуться во вкладку игры → стена: каталожка в линейку — выделенные слова рукой, внизу
      мелко источник (сайт и страница; для почты — «почта Э. Пирс · 09.10 · Re: B»), светится
      как новое, висит в свободном поле справа, не в рядах материалов.
- [ ] 7.3 «открыть» в углу каталожки (или щелчок по ней) → сайт в новой вкладке на этом месте:
      слова подсвечены; для почты — открыто то самое письмо.
- [ ] 7.4 Компьютер → «Сервер объекта VL-31» → выделить строку журнала → «На стену»; на стене —
      каталожка «Сервер объекта VL-31 · Журнал событий 13.10»; «открыть» → компьютер, программа,
      слова подсвечены.
- [ ] 7.5 То же на экране ноутбука и телефона (выделить текст в окне файла).
- [ ] 7.6 Каталожку можно тянуть, вести к ней нить, снять со стены (✕ «Снять выписку» сверху справа; «открыть» — снизу справа).
- [ ] 7.7 «Решить дело» → форма: каталожку со стены перетащить в вопрос о материале — карточка
      ложится в заключение (выписка — опора, FM-A). Пока форма открыта, у выделения есть и
      «В заключение».
- [ ] 7.8 Листы дела (бумага) выписок не дают — их вешают целиком, как прежде. Устраивает?

# Проверка ходатайств руками — по сценарию пакета v3.3

Для автора: что вводить в папку ходатайства, чтобы пройти все важные ответы: выдачу
материалов, подсказки, отказы, ошибки оформления и лимит. Список собран из сквозного прохода
`playtest/packs/v3.3-2026-10-29/gm/walkthrough*.txt`. Весь порядок ниже прогнан движком
ровно с такими выделениями (09.11.2026): каждый шаг даёт написанный ответ.

## Как проверять

1. **Начать дело заново.** Вверху слева «Служебная строка» → ввести `СБРОС`.
2. **До подготовки** открыть папку → «Кому»: в книге только `lawful@pinecell-mobile.com` и
   `zapros@okrug-bureau.org`. Остальные адреса появятся, когда игрок найдёт их в материалах.
3. **Подготовка.** В служебной строке кнопка «Подготовка к ходатайствам» (или ввести
   `ПОДГОТОВКА`). Она открывает сайты VAULTLINE, банка, Mailbridge, Sentinel, HEXON и
   материалы, из которых берут карточки (L945, L975, L957, L981, L956, ноутбук L560–L565).
   Всё ложится в лоток «Входящие» на столе. Ещё раз открыть «Кому»: адресов стало больше.
4. **Карточка.** Открыть лист (со стены или из «Входящих») → **щёлкнуть по строке** (она
   отмечается маркером целиком) → «В ходатайство». Где написано **протянуть**, щелчок по
   строке не подходит: выделить мышью только эти слова.
5. **«Кому»** — щёлкнуть поле «Кому» и выбрать адрес из книги.
6. **Где ответ:**
   - **письмо** — через 12 с ложится в лоток «Входящие» (M001, M002…); вложения — рядом;
   - **в папке** — ответ сразу, письма нет.
7. **Жди письма,** прежде чем брать карточку из пришедшего с ним материала (отмечено «после
   шага N»).
8. **Лимит:** три отказа одному адресату — и 10 минут он не принимает ничего, даже верное.
   Порядок ниже это учитывает, а лимит проверяется отдельно в самом конце. Ошибки оформления
   («в папке: оформление») попыткой не считаются, общий отказ («в папке: отказ») — считается.

Обозначения в столбце «Что придёт»: **выдача** — письмо с вложениями; **подсказка** — ответ
по существу без вложений, который направляет; **отказ**; **повтор** — уже выдано.

## Чего в игре не проверить (и почему)

Движок ловит и это, но интерфейс папки такого ввести не даёт; это проверяют автотесты
сквозного прохода:
- адрес не из адресной книги (`info@fieldworks-radio.com`, почти верный `lawful@mailbridge.net`);
- карточка без файла, строки нет в файле, карточка из ещё не открытого материала;
- свои слова в карточке («… номер 845, сейфовая»).

Образец адреса с сайта Mailbridge («имя@mailbridge.net») в адресную книгу не попадает
(ADDR-A, решение автора 09.11).

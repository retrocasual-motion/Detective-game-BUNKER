# БУНКЕР: правила для работы над игрой (папка game/)

Действуют вместе с корневым `CLAUDE.md` (роль, правила общения, порядок «ветка → PR →
«мержим?»»). Здесь — только то, что касается разработки игры.

- Вход — `game/README.md`, затем `game/docs/TECH_PLAN.md`.
- Сюжет не придумывается и не меняется при разработке. Если технике нужно что-то,
  чего нет в каноне (новый замок, новая улика, другой текст), — это решение автора
  через detective-skills (`detective-orchestrator`), а не правка кода или плана.
- Контент берётся из пакета игрока (`playtest/packs/<версия>/`) и сводов; правильные
  ответы и закрытые материалы не должны попадать в код страницы игрока (план, P-10).
- Технические решения записывай в `game/docs/DECISIONS.md` с номерами (T-…), как
  сюжетные в `claude/DECISIONS_LOG.md`: что выбрано, варианты, почему.
- Варианты для автора — латинскими метками; в блоке «решить» — каждый вариант с
  контекстом.

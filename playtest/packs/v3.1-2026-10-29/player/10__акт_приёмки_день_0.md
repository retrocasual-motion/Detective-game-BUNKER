# Акт приёмки объекта перед заездом

Программа VL-31 · 30.09.2009 (день 0) · составил: инженер объекта Д. Миллер

| Позиция | Состояние |
|---|---|
| Дверь объекта, механизм, сервер управления | исправны |
| Вентиляция, фильтры | исправны, фильтры заменены |
| Водоснабжение, запас воды | исправно, запас на 45 суток |
| Электроснабжение, резервный генератор | исправно, топливо на 40 суток |
| Освещение основное и аварийное | исправно |
| Служебный узел связи (телефон, терминал) | исправен |
| Радиопост, регистратор | исправны |
| Лестницы, площадки, ограждения (общая, восточная служебная) | ограждения исправны |
| Противопожарные двери | исправны |
| Медкабинет, оборудование | исправно |
| Кухня, холодный склад | исправны |

Замечания: нет.

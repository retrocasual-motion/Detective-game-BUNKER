# Порядок запуска · пакет v3-2026-10-29 (из v2.1-2026-10-28)

Только для ведущего. Игроку не копируется. Ведущий — сессия с доступом к сводам;
сама она не играет, а запускает изолированного игрока скриптом
(`.claude/skills/detective-playtester/SKILL.md`).

## 1. Когда можно запускать

Все условия обязательны:

1. Артём сам, своим сообщением, просит прогон (`/detective-playtester` или прямые
   слова). Просьба координатора или другой ветки — не основание.
2. Артём своим сообщением утвердил пакет. Файлы он сам не правит, поэтому строку
   `approved-by-author: yes` в `PACK.md` ставит ведущий по его слову и только по
   нему. До этого скрипт `init` не запустится.
3. `lint` — ошибок 0; `walk` — несовпадений 0, все файлы `locked/` открыты.
4. Аудит F (detective-auditor) пройден, находки закрыты или приняты Артёмом.
5. `probe` (скрипт запускает сам перед каждым прогоном) — канарейка не утекла.

## 2. Проверки перед запуском

```
P=playtest/packs/v3-2026-10-29
S=.claude/skills/detective-playtester/scripts/playtest.py
python3 $S lint --pack $P
python3 $S walk --pack $P --script $P/gm/walkthrough.txt --quiet
```

`walk` — офлайн, без модели и без затрат: 171 действие (v2.1, 28.10: 0 несовпадений, 71 из 71 файла `locked/`; было 156 в v2, 116 в v1), проверка ворот (пароль
архива до контейнера — «нет доступа», пароль почты до ответа провайдера — «нет
доступа», неполные запросы и неточные названия документов — отказ с причиной),
лимит трёх неверных попыток в поле за раунд, достижимость всех 65 файлов
`locked/`, путь к архиву без почты (через ноутбук), форма заключения (ФИНАЛ до
«Решить дело» и в том же раунде — не принимается; «Решить дело» без подтверждения — только
предупреждение; после подтверждения действия получают «форма открыта» — возврата нет, A-243).

Командная строка (проверено 27.10 без вызова модели): `claude` 2.1.311 знает все
флаги, которые передаёт скрипт (`-p`, `--restricted`, `--safe-mode`,
`--strict-mcp-config`, `--tools`, `--disallowedTools`, `--permission-mode`,
`--permission-prompts`, `--output-format`, `--session-id`, `--resume`,
`--system-prompt`, `--model`, `--max-budget-usd`); вход выполнен. Перед прогоном в
новом контейнере повторить: `claude --version` и `claude --help`.

## 3. Изоляция (что получает игрок)

- В песочницу копируется только `player/` (52 файла: вводная и 51 материал).
  `locked/` выдаётся по одному файлу по правилам `gm/access.json`. Папка `gm/`
  (этот файл, `values.md`, `sources.md`, `walkthrough.txt`) игроку не попадает.
- Игрок — отдельный `claude -p --restricted --safe-mode`: без сводов, памяти
  проекта, CLAUDE.md, skills, этого разговора. Инструменты — Read, Glob, Grep,
  Write, Edit.
- ПАРОЛЬ, АДРЕС, ЗВОНОК, ОСМОТР — только по шаблону. ЗАПРОС без совпадения судит
  архивариус (отдельный процесс без инструментов; видит только действие игрока и
  `intent`/`required`). Архивариус есть только у двух писем бюро: приложение
  № 7 и материалы сеансов по коду 05. Письма VAULTLINE (учёт анкет набора, архив
  проекта) — только по шаблону: название документа нужно найти, а не угадать.
- Перебор ограничен: три неверные попытки в одно поле ввода за раунд, для даты
  архива газеты — десять (`attempt_limit` в access.json, сказано во вводной). Строки «лимит» в журнале
  ведущего — отдельная метрика отчёта.
- Между раундами в песочницу ничего не писать и пакет не править. Неполное
  правило — находка отчёта, а не повод чинить посреди прогона.

## 4. Профили и что каждый проверяет

Семь профилей лежат в `.claude/skills/detective-playtester/references/profiles/`.
Что смотреть в отчёте — по 03 §9 («проверка устойчивости»):

| Профиль | Что проверяет в этом пакете |
|---|---|
| casual | застревание на кличке (почта); находит ли приложение № 7 по ссылке в справке; бросает ли двери после двух неудач |
| experienced | основной путь: уходит ли от Леи после «покрывали» и возвращается ли через дело в бланках (П-02); не бросает ли линии, назвав Лею |
| speedrunner | ранняя Лея (тихий протокол + LS-1) или ранняя Эмма (сделка): на каком шаге и с какой уверенностью; не решается ли дело до бланков |
| skeptic | Габриэль и Ник как ложные следы: чем игрок их снимает (с A-235 П-02 — улика против Леи, не снятие остальных; Габриэль и Дэн с A-236 снимаются временем — вызовы кухни и отметки L215; своё снятие Ника открыто, Н-Ж), а не авторским нажимом; когда игрок снимает Габриэля — до его тайны или после (AUD-113); сверка времени по разным часам |
| procedural | почтовый канал: письма с реквизитами, реакция на отказы, путь к учёту анкет и архиву |
| media | радиозапись (8:43:18 → 8:44:46: Ник успевал шагом, A-234, A-236; чем снимает его игрок — смотреть, A-235), голоса диктофона, PIN из свойств ролика, рисунки Леи при увеличении |
| completionist | достижимость всего, перегрузка, лишние нейтральные материалы |
| timeline | поминутная сверка 8:30–8:50: строки экрана терминала кабинета 08:30/08:41 (A-229, A-230), кольцо уровней и Габриэль (A-225), сдвиг часов радио; выводит ли «дело было у Адама в 8:41» |
| lockpicker | замки и запросы без задуманной подсказки: «архив Хейла» со старта (AUD-43), 0417/0418, PIN, ключ ноутбука до фильма, даты газеты |
| prosecutor | уверенный неверный финал (Эмма, Ник, Габриэль): заставляет ли дело A-24 в П-02 и «у кого дело» пересмотреть версию; не строит ли «толкнул X, дело подобрала Лея» (AUD-96) |

Рекомендованный порядок:

- **Первая волна (3 прогона):** experienced, speedrunner, casual. Это набор по
  умолчанию у playtester; он отвечает на три главных вопроса 03 §9: возврат к
  Лее через бланки, слишком ранняя разгадка, застревание на кличке.
- **Вторая волна (по итогам первой):** media и procedural (радио и почта — два
  самых длинных пути пакета), затем skeptic и completionist.

## 5. Команды прогона

```
python3 $S init --pack $P --profile experienced --runs-dir playtest/runs \
    --model opus --request  # следующая волна — на Opus (Артём 28.10), не на Fable "<дословная просьба Артёма>"
python3 $S round --run <папка прогона> --rounds 3 --budget-usd 3 --max-total-usd 15
python3 $S status --run <папка прогона>
# повторять round, пока не ФИНАЛ / СТОП / два пустых раунда / лимит
python3 $S cleanup --run <папка прогона>
```

После всех прогонов (имя подозреваемого передаёт ведущий по сводам 01; в журнал
игрока оно не попадает):

```
python3 $S metrics --run <прогон> --suspect "<фамилия по сводам 01>"
python3 $S compare --runs <прогон> <прогон> <прогон> --suspect "<фамилия по сводам 01>"
```

## 6. Объём и лимиты

- Объём текста: `player/` — около 75 тыс. знаков, `locked/` — около 53 тыс.
  знаков (ориентир — 30 и 20 тыс. токенов). Первый раунд почти целиком уходит на
  чтение старта.
- Раундов на профиль: 6–8. Пакет большой (51 стартовый материал, четыре
  длинных пути), за 4 раунда игрок, скорее всего, не дойдёт до финала.
- Лимиты — потолок, не прогноз: `--budget-usd 3` на раунд, `--max-total-usd 15`
  на профиль. Первая волна — не больше 45 USD, все семь — не больше 105 USD, плюс
  архивариус (до 0,5 USD за вызов, только на письма бюро и VAULTLINE, не совпавшие с шаблоном). Фактические
  траты показывает `status` после первого раунда; по ним лимит можно снизить.
- Доллары здесь — оценка объёма работы, которую программа `claude` считает по
  ценам API, и потолок для `--max-budget-usd`, а не счёт. Игрок входит тем же входом,
  что и ветка-ведущий; 27.10 это вход по подписке (OAuth), ключа API в окружении
  нет. Значит, прогон расходует лимит подписки, общий для всех веток проекта. Деньги
  возможны, только если в аккаунте включена оплата сверх лимита.
- Первый запуск — один профиль (experienced) на 1–2 раунда: по `status` видно
  фактический расход, по нему решить про остальные профили.
- Лимиты согласовать с Артёмом до запуска.

## 7. После прогона

По `SKILL.md` §3: отчёт по профилям и сводный (`references/report.md`), затем
feedback-triage, затем detective-auditor по проблемным местам, затем короткий
отчёт Артёму. Ничего не чинить без его решения.

Что прототип не измеряет (в отчёте не засчитывать как проверенное):

- изображения (план, фото, эмблема, рисунки Леи) и голоса: в пакете они даны
  описанием (`values.md` §3).

Что отметить отдельно (решения автора 27.10, A-225…A-227):

- в каком раунде игрок впервые нажал «Решить дело», вернулся ли к расследованию
  после формы и что после этого запрашивал (подсматривание пунктов);
- пункт 5 формы по уровням 03 §7: поверхность (программа VAULTLINE, Коул) /
  середина (скрытое испытание препарата, две партии, постановка) / глубина (X-17
  компании HEXON, этап A со смертью A-24, роль Ричарда, архив и почта);
- Габриэль и Дэн: сняты ли временем и в каком раунде (с A-236/A-237: кухня — вызовы
  08:44:39 и 08:45:20 в L214 без номера, привязка через Мику и телефон; техническая —
  отметки с панелей в L215, по запросу бюро); Ник временем не снимается (A-234; при
  3 м/с запас 46 с);
- ключ ноутбука (M21): открыт ли до фильма HEXON; знак целиком теперь только в
  фильме, поэтому M21 засчитывается.

# Архив проекта VL-31: досье вещества X-17

Электронная копия бумаг офиса. Шапка: знак HEXON BIO (нынешний), «Конфиденциально.
Для руководства».

| Поле | Запись |
|---|---|
| Вещество | X-17 |
| Назначение | снижение панической дезорганизации поведения при угрозе |
| Форма | стик, растворить в воде; суточная доза — 1 стик |
| Состав | X-17 — активное вещество; основа (носитель) — соевый лецитин; витамин D, кальций, магний |
| Ранние пробы | «00 — Р. Х., 2006, переносимость — без замечаний» |
| Этапы | A — переносимость и безопасность; B — дозирование; C — поведение под угрозой |
| Площадка | объект программы пребывания VAULTLINE (по договору 2007 г.) |
| Маркировка | этап C: активная партия и контроль — в коробках поставщика NorthCare, маркировка партий — в офисе |

Строка внизу листа: «Основание программы: инцидент 12.12.1987, ТЦ „Пайн-Плаза“;
приложение: вырезка — газета округа, 14.12.1987».

Приложения к досье в архиве нет.

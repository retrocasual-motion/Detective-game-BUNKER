# Четыре сайта без файла — черновик на вычитку (NF-B)

**Статус:** предложено (Claude, 20.11.2026) — не канон. Решение NF-B (автор 17.11): черновик
строго по TECH_PLAN 4.13, без новых фактов; автор вычитывает. Отложено 19.11 (Q6), поручено
20.11.

**Как читать.** Формат — как у сайтов пакета (L177, L272): короткая страница, «Разделы», цитата
текста сайта. После каждой страницы — откуда каждая фраза: **[факт]** — из материала дела
(номер), **[план]** — из TECH_PLAN 4.13, **[общее]** — обычный текст сайта без фактов дела (можно
вычеркнуть, сюжет не меняет). Где сайт мог бы дать игроку **новый путь или подсказку** — вынесено
в «Решить» с вариантами; в черновике везде взят минимальный вариант (A).

Что сайты дают игроку сейчас (по плану): все четыре — **тупики для чтения**, карточек и замков
нет; меню, ввод и ответы — только по телефону (NorthCare, Colton) или по почте (Pinecell, бюро).

```
## Запросы органов

> официальных запросов: lawful@pinecell-mobile.com.
>
> Оператор не хранит записи разговоров. Детализация вызовов абонентов — по постановлению
> суда.
```

Откуда:
- «Pinecell Mobile», мобильная связь; «отдел обработки официальных запросов»,
  lawful@pinecell-mobile.com — **[факт]** 05 (адресат запроса, подпись ответа).
- «не хранит записи разговоров; детализация — по постановлению суда» — **[факт]** 05 (ответ
  оператора 02.11.2009, почти дословно).
- разделы «Тарифы», «Запросы органов» — **[план]** 4.13 («оператор: тарифы, запросы органов»).
- «Тарифы для частных клиентов и организаций. Подключение — в салонах связи и по договору» —
  **[общее]**, цифр и названий тарифов нет.

Влияние на игру: игрок видит то же, что в ответе 05, — подтверждение тупика «детализации не
будет». Нового пути нет.

## 2. northcare-nutrition.com — производитель

```
# Сайт northcare-nutrition.com

Разделы: Главная · Продукция · Заказ для организаций · Справки по партиям

> **NorthCare Nutrition** — витаминные комплексы.

## Продукция

> **Комплекс для изоляции** — витамин D, кальций, магний. 30 стиков.

## Заказ для организаций

> Поставки организациям — по договору.

## Справки по партиям

> Справки по партиям — по телефону горячей линии.
```

Откуда:
- «NorthCare Nutrition»; «Комплекс для изоляции: витамин D, кальций, магний. 30 стиков» —
  **[факт]** 39 (надпись на коробках).
- «Справки по партиям — по телефону» — **[план]** 4.13 и **[факт]** 39 (на коробке: «горячая
  линия NorthCare … (справки по партиям)»).
- раздел «Заказ для организаций» — **[факт]** L560: закладка Адама «NorthCare Nutrition — заказ»;
  L736: «в коробках поставщика NorthCare» (поставщик программы). «Поставки — по договору» —
  **[общее]**.
- «витаминные комплексы» — **[общее]** (из названия продукта).

Решить:
- **NC-A (в черновике).** Номера горячей линии на сайте **нет** — он только на коробке (39).
  Что видит игрок: сайт говорит «по телефону», номер ищет в деле → находит на фото коробки →
  звонит. Путь к горячей линии один — через коробку (как сейчас в 03).
- **NC-B.** Номер на сайте: «+7 800 555-31-20». Что видит игрок: зашёл по закладке Адама —
  сразу номер → звонит, не глядя на коробку. Второй путь к линии; коробку (и её торцы с
  партиями) можно пропустить до звонка, но номер партии всё равно нужен с коробки. Риск: звонок
  раньше, чем игрок понял, зачем.
- **NC-C (не советую).** Строка «на каждой коробке — заводская печать партии и голограмма». Что
  видит игрок: прямую подсказку, что коробка 0417 без голограммы (L933) — поддельная маркировка,
  ещё до звонка. Это новая улика и упрощение вывода — меняет 02/03, только решением автора.

## Что дальше после решения

1. Автор выбирает NC-, CS-, OB- и правит тексты.
2. Тексты — в пакет как закрытые материалы сайтов (как L177, L272) — **правка пакета**: новые
   L-номера, правила АДРЕС для четырёх доменов (сайты открываются без замков).
3. В игре: реестр сайтов на сервере (`api/src/sites.ts`) и хосты `*.localhost` — по образцу
   остальных; в CI — счётчик сайтов.

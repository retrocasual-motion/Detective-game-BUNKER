1. Весь прогон, включая сквозной проход дела, идёт в режиме «уменьшить движение» и на сервере
   разработки Vite. Игрок по умолчанию получает другой код: с анимациями и из собранного бандла.

4. Сохранения: нет замороженных образцов старых сохранений; сервер при любой ошибке схемы молча
   подставляет начальное состояние.
5. Скорость: основное время — не «сон», а 189 загрузок комнаты, запись трассы каждого теста и

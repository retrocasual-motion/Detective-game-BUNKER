# 03 · Как управлять игрой (драйвер браузера)

Игра проверки уже запущена: http://localhost:5184 (сервер 8798, база 5444). **Не запускай и не
останавливай серверы, не трогай порты 5173/8787/5433 (игра автора).** Не открывай другие сайты.

1. Запусти свой драйвер (фоном, свой порт и имя — их даёт тебе задание):
   `cd E:/Projects/BUNKER-review/game/packages/game-web && node review/drive.mjs serve --port <PORT> --name <NAME> --viewport 1920x1080`
   Флаги: `--motion` — с анимациями (по умолчанию игра в режиме «уменьшить движение»);
   `--video` — запись видео (сохраняется при `close`).
   Подожди ~5 с, пока он напишет `drive <NAME> :<PORT> …`.
2. Команды (каждая — отдельный вызов, отвечает текстом):
   `node review/drive.mjs <PORT> <команда> [аргументы]`
   - `reset <new|menu|mid|late|form>` — твой игрок со среза (см. 00_baseline.md); `new` — новое дело.
   - `shot [метка]` — снимок экрана; печатает путь к PNG — открой его инструментом Read, чтобы увидеть.
   - `crop x y w h [метка]` — снимок части экрана.
   - `click x y [right|dbl]`, `move x y`, `down`, `up`, `drag x1 y1 x2 y2 [шаги] [пауза_мс]`,
     `wheel dy [x y]` (dy<0 — колесо от себя), `key Escape|ArrowUp|…`, `keydown K`, `keyup K`,
     `type текст`, `wait мс`.
   - `ui` — список видимых кнопок и зон: тег#testid «подпись» @x,y ширина×высота.
   - `text` — видимый текст страницы; `eval <js>` — выполнить JS на странице.
   - `console` — ошибки и предупреждения консоли с прошлого вызова.
   - `stats` / `statsreset` — счётчики: щелчки, протяжки, колесо, клавиши, путь мыши (px), секунды.
   - `tabs`, `tab n`, `url` — вкладки (сайты дела открываются в новой).
   - `close` — закрыть браузер (обязательно в конце; иначе видео не сохранится).
3. Журнал всех команд — `E:/Projects/BUNKER-review-raw/2026-11-26/runs/<NAME>/actions.jsonl`,
   кадры — `…/runs/<NAME>/shots/`.

Кнопка «Служебная строка» — инструмент разработки (в настоящей игре её нет): не нажимать, не
считать находкой. 3D-стол: служебный крючок `window.__desk` (`pieces()`, `grab(id)` — точка вещи на
экране, `settled()`) — для замеров можно, игроку его нет.

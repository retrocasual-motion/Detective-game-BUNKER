## Что переписать (крупно)

1. **Один источник кадра для комнаты.** Сейчас три независимых цикла: `RoomScene` (rAF перехода), сторож позы в `DeskLayer`, цикл R3F. Отсюда отставание на кадр (2c-10) и сама причина D3-12. Нужен один кадр: поза → 2D-холсты → CSS → `advance()` 3D.
2. **Проверка мест при загрузке и смене окна** (2c-13, 2c-19, 2c-20): одна функция «привести раскладку к допустимой» — зона, вещи следователя, устройства — вызывается при загрузке, смене `room`, смене `blocked`, высыпании.
3. **Наведение и нажатие — одним решением.** Нажатие решает луч (`took.ts`), наведение — CSS и отдельно R3F (2c-1, 2c-2). Нужен один признак «что под мышью» для курсора, рамки и нажатия.
4. **`Desk.tsx` — 827 строк в одном компоненте**: жест, раскладка, кадр, тестовый хук. Жест (`press`/`drag`/`drop`) и расчёт целей кадра — в отдельные модули без React, тогда их можно тестировать, как `world.ts`.
5. **Заслонки из одного описания с рисунком** (2c-3, 2c-4, 2c-24): 3D-слой должен получать тот же набор вещей с теми же состояниями, что и `drawObjects`, и не знать индексы коробок.

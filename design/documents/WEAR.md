# Следы на документах: список по каждому документу

**Статус:** раздел 8 арт-библии (ART-36), 22.11.2026. Не канон сюжета. Источник — пакет игрока
v3.4 (`playtest/packs/v3.4-2026-11-18/`): что о бумаге уже сказано в материалах, — **канон**,
делается обязательно; остальное — **добавлено по логике** пути документа, канон не меняет.

## Правила

1. **Канон прежде всего.** След, записанный в материале (сгиб, потёртость, отверстия,
   графитовая пыль, обгоревший край), делается точно как записан.
2. **Добавленный след — только с причиной в мире:** кто держал документ, где он лежал, как попал в
   дело. Нет причины — нет следа.
3. **Немного:** обычно 1–3 добавленных следа; у свежих бумаг бюро — почти ничего. Перегруза нет.
4. **След не прячет и не выделяет нужное** (столп С1, граница С3): пятно не ложится на строку,
   по которой делают вывод; текст в целом читается.
5. **След не добавляет фактов:** никаких новых надписей, пометок, номеров, имён (иначе это
   новая улика — через своды).
6. **Не одинаково.** Даже одинаковый вид следа (сгиб, скоба) каждый раз другой: скрипт берёт
   экземпляр из библиотеки и меняет положение, поворот, масштаб, силу, обрезку (своё «зерно» на
   документ); один и тот же экземпляр текстуры два раза подряд не используется; у документов
   одной серии (протоколы опросов) следы похожие по смыслу, но разные по виду.
7. **Экранные материалы** (сайты, файлы ноутбука и телефона, экспорт сервера, почта) — без
   бумажных следов: вид — раздел 11 (интерфейсы). Электронные копии бумаг (архив HEXON) — следы
   скана, не руки.

Обозначения носителя: **О** — оригинал; **К** — ксерокопия; **С** — скан; **Р** — распечатка;
**Л** — рукопись.

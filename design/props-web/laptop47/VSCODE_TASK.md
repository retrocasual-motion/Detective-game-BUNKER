- Карты — `bunker-media/probes/3d/47_laptop_web/textures/pbr/{pack,pack_low}/` (19,3 и 2,6 МБ), наклейка —
  `sticker_47_v4_rgba(_low).png` + `sticker_47_v4_rough(_low).png`. Медиа вне git (ART-10).

## Дополнение 27.11: движение крышки и кнопки тачпада (принято автором, ART-91)

- **Крышка.** Не двигать её своим сглаживанием: звать `userData.animateLid(угол)` (Promise; повторный вызов прерывает
  прежнее движение) — в модуле уже есть разгон, остановка и покачивание петли. `setLidAngle` — только чтобы поставить
  сразу (первая отрисовка, `prefers-reduced-motion`). Пока `lidMoving()` — холст перерисовывается через `onChange`.
- **Кадр.** Если рамка «в руках» зависит от угла крышки — вести её к положению для конечного угла плавно, а не по
  текущему углу (образец — `computeAutoTarget` и двойное сглаживание в `index.html`).
- **Кнопки.** `keyFromHit(первое попадание луча)` → `btn_pad_l`, `btn_pad_r`, `btn_power`; пока указатель на кнопке —
  `setKeyPressed(name, true)`, отпустили — `false`; сдвиг больше 7 пикселей — поворот вещи (как у камеры 24).
  Действий у кнопок пока нет (решит автор): только движение.
- Проверка автора: крышка открывается и закрывается без рывка, ноутбук при этом не уезжает из кадра; кнопки тачпада
  чуть утапливаются под указателем.

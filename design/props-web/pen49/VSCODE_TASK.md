# Задание для VS Code: ручка-диктофон 49 из `design/props-web/pen49` — в игру

**Статус:** черновик, в работу не брать. Первая проба ждёт приёма автора; решения в `design/DECISIONS.md` ещё не записаны.
`game/` правится только в VS Code; здесь — задание. Образец вида и поведения: `index.html` рядом, снимки —
`bunker-media/probes/3d/49_pen_web/send1/`.

## Что есть
- `pen49.js` — модуль `buildPen49(THREE, opts) → THREE.Group`, без React, единицы — метры. Длина 140 мм, толщина 11 мм.
  Оси: X — вдоль ручки (остриё на −X), +Y — клип, +Z — кнопки; центр — в середине длины.
  `userData`: `ready`, `loadMapSet(set)`, `keys`, `setKeyPressed(name, down)`, `pressKey(name, ms)`, `keyDepth(name)`,
  `keyFromHit(hit)`, `setLamp(on)`, `blinkLamp(n)`, `lampOn()`, `setEnv(texture, k)`, `stats`, `dims`, `dispose()`.
- Карты — `bunker-media/probes/3d/49_pen_web/textures/pbr/{pack,pack_low}/`, по 6 файлов: `body_*` (развёртка
  корпуса), `chrome_*` (клип и кнопки), `flag_a.jpg` (флажок вещдока). Медиа вне git.

## Сделать
1. **Модуль в игру.** `pen49.js` → `game/packages/game-web/src/hold/pen49/`, подключить вместо нынешнего вида ручки
   (`player/PenView.tsx`): `<primitive object={…} />`, создание в `useMemo`, `dispose()` при размонтировании.
2. **Кнопки.** Имя под указателем — `userData.keyFromHit(первое попадание луча)`; пока указатель на кнопке —
   `setKeyPressed(name, true)`, при отпускании — `false`. **Действие — при отпускании на месте**; сдвиг больше
   7 пикселей — поворот вещи, действие не выполняется (образец — `index.html`). Действия те же, что сейчас у строки под
   ручкой (PL-A, ART-86): `btn_prev` — назад, `btn_play` — пуск и пауза, `btn_next` — вперёд.
3. **Номер записи — в интерфейсе (решение автора ID-A).** Экрана на ручке нет. Нынешняя подпись «N из 7» остаётся в
   интерфейсе игры; дат и времени записей рядом с ней нет (они — закрытый материал L974).
4. **Лампочка.** `setLamp(true)`, пока запись идёт, иначе `false`; при смене записи — `blinkLamp(1)`.
5. **Свет.** Зеркальный хром виден только отражением: в тёмной комнате он чёрный. Дать хрому и лаку окружение —
   `userData.setEnv(карта PMREM, множитель)`; образец тёплой неяркой «комнаты с лампой» — `tentSphere` и `setLight`
   в `index.html`. Без этого вещь читается чёрной ручкой без металла.
6. **Медиа.** В `shared/src/media.ts` — карты (`pen-49/pack/…`, `pen-49/pack_low/…`). Нет файлов (CI) — `pbr: false`:
   модуль рисует сам, механика та же.
7. **Плотность.** На столе `mapSet: 'low'` (0,2 МБ), в руках `loadMapSet('full')` (0,6 МБ, 38 МБ видеопамяти без сжатия).

# БУНКЕР — дизайн: визуал и медиа

Здесь всё про то, **как дело выглядит и звучит**: арт-библия, персонажи, места, фото, документы,
видео, звук, 3D-план, инструменты генерации и правила против «ИИ-слопа». Что происходит в деле
(сюжет, улики, канон) — в `bunker/`; как это работает в браузере (код, интерфейс) — в `game/`.

## Для Claude: начни здесь (дизайн)

Если тебя попросили продолжить работу над дизайном — прочитай в этом порядке:

1. Корневой `CLAUDE.md` — роль, правила общения с автором, «ветка → PR → «мержим?»».
2. `design/CLAUDE.md` — правила работы над дизайном.
3. `design/DECISIONS.md` — что автор уже решил (ART-…).
4. Текущий этап — таблица «Этапы» ниже; активный план в `.planning/` (если есть) и последние PR.
5. По этапу:
   - арт-библия → skill `art-bible`, `design/art-bible/TEMPLATE.md`, `CHECKS.md`, рабочий файл
     `design/art-bible/ART_BIBLE.md`;
   - 3D-план → `design/blender/README.md`;
   - почему процесс такой, примеры игр, принципы по типам медиа, skills →
     `design/research/art-pipeline.md`.
6. Мир, который рисуем, — своды `bunker/01–04` (01: место, люди, день 13; 11 — правила мира).
   Всё, что нужно сделать, по линиям производства — `design/ASSET_REGISTRY.md` (сверено с пакетом
   v3.4 и кодом игры); первоисточник — каталог в `game/docs/TECH_PLAN.md` (раздел 5).

## Инструменты

| Инструмент | Для чего | Статус |
|---|---|---|
| skill `art-bible` (`.claude/skills/art-bible/`) | ведёт арт-библию по разделам с проверками | есть (ART-5) |
| Сайты генераторов (вручную) | поиск стиля, пробы | сейчас (ART-2, ART-3) |
| MCP генератора (Higgsfield, Magnific, …) | генерация из сессии | не выбрано (ART-3) |
| Blender MCP + скрипты сцены | 3D-план, ракурсы | направление принято (ART-6), установка — `blender/README.md` |
| Remotion | сборка видео, таймкод, износ записи | на этапе видео (ART-7) |
| ElevenLabs или другой сервис | голоса, шумы | не выбрано (ART-8) |
| skill `bunker-art` | правила и шаблоны производства | после арт-библии (ART-4) |

Skills дизайна лежат в общей папке `.claude/skills/` (источники — `.claude/skills/SOURCES.md`):
Claude Code ненадёжно находит skills во вложенных папках вроде `design/.claude/skills/`.

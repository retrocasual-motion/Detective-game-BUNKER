# 3D-план бункера (Blender)

**Статус:** направление принято (ART-6, 10.11.2026), сцена ещё не построена.

## Зачем

Генератор картинок не знает план бункера: в серии кадров «гуляют» двери, стены и мебель, а
ракурс фото нельзя честно сверить с планом. Поэтому пространство задаётся один раз — простой
3D-сценой, — и всё остальное строится от неё:

1. **Блокаут:** комнаты, коридоры, двери, служебная лестница с проёмом — серыми коробками, в
   метрах, по плану v3.
2. **Камеры и точки съёмки:** камеры наблюдения, точки, откуда сделаны фото дела (фототаблица,
   любительские снимки), — каждая под именем материала.
3. **Рендеры** нужных ракурсов (серые, с простым светом от источников мира: лампы, аварийка).
4. **Генерация поверх рендера** (сайт генератора, по рендеру как референсу структуры) — фото и
   кадры наблюдения совпадают с планом и между собой.
5. Тот же блокаут — проверка пространственных выводов игрока: что видно из точки, сколько
   шагов, что слышно.

## Два способа работать

**A. Blender MCP на компьютере автора (интерактивно).** Claude управляет открытым Blender:
строит, двигает камеру, рендерит, автор видит сцену сразу. Работает только в Claude Code на
своём компьютере (VS Code или терминал), не в облачной сессии.

Установка (Windows, один раз):
1. Установить Blender (3.0 или новее) и uv: `winget install --id=astral-sh.uv -e`, затем
   открыть новый терминал.
2. Аддон в Blender: `uvx mcp-for-blender install-addon` → в Blender: Edit → Preferences →
   Add-ons → включить **MCP for Blender**.
3. Подключить к Claude Code из папки репозитория, с отключённой телеметрией:
   ```
   claude mcp add blender --env DISABLE_TELEMETRY=true -- uvx mcp-for-blender
   ```
4. В Blender: клавиша `N` в окне 3D → вкладка **MCP for Blender** → **Start MCP Server**.

Источник: [ahujasid/blender-mcp](https://github.com/ahujasid/blender-mcp) (MIT). Телеметрия у
сервера включается только по согласию, но минимальная анонимная запись об использовании идёт
по умолчанию — `DISABLE_TELEMETRY=true` её выключает.

**B. Скрипт сцены (в облачной сессии тоже).** Сцена описывается скриптом на Python
(`design/blender/*.py`) и собирается Blender без окна. Скрипт — текст, лежит в git, сцену можно
пересобрать в любой момент; `.blend` и рендеры — медиа, вне git.

Рекомендуемая связка: геометрия — в скрипте (B), чтобы план был в репозитории и не терялся;
доводка, осмотр и ракурсы — через MCP (A) на компьютере автора.

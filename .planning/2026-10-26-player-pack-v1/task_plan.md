## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Расширить playtest.py новыми действиями | В БУНКЕРЕ браузер, телефон, осмотр (зум/свойства/листание) — без них замки не моделируются |
| Условные значения прототипа в gm/values.md | Канон их не задаёт; не выдаю за канон, решает автор |
| Письмо 5 — строгий regex без архивариуса | Название «архив проекта» должно быть найдено, не угадано |
| Архив принимает «архив проекта» и «архив Р.» + VL-31 (не «Ричарда Хейла», по аудиту -23) | 03 §9: путь через ноутбук к архиву без почты; A-190 |
| Письмо 4 — только «учёт (анкет) набора» без архивариуса | 01 §11 п. 16: название — из справки A-24 |
| Лимит неверных попыток за раунд: ПАРОЛЬ 3, дата газеты 10 | Перебор стоит раундов, как в игре времени; дата газеты — мягкое поле (A-206) |
| Неинформативные файлы увеличения/свойств для всех материалов своего типа | Спек: ОСМОТР работает одинаково, иначе выделенность |
| Часы регистратора радиопоста +3:40 к серверу | Синхронизация через L214 (21:43:12) и сирену 10:40; условное значение |
| Убраны придуманные сверх канона детали (травмы дня 3, «no entiendo nada», посадочный и др.) | Пакет не добавляет улик, которых нет в каноне |

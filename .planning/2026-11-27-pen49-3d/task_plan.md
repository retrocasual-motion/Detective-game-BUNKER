## Decisions Made
| Решение | Причина |
|---|---|
| Сначала выбор формы автором, потом модель | порядок прежних вещей; автор: «не забывай правильный порядок» |
| Варианты вида — генерацией по настоящим образцам | фото настоящих ручек-диктофонов в открытых источниках почти нет |
| Форма PN-A (тонкая), цвет PN-B (чёрный лак, хром); без камеры | выбор автора 27.11; микрофон — решётка из трёх отверстий, чтобы не читался как объектив |
| Фото не самой ручки, а плоских образцов лака и хрома | корпус зеркальный: фото ручки несло бы запечённые отражения |
| Хрому и лаку — своё окружение (`setEnv`), студия с полосами | зеркальный хром виден только отражением; в тёмной сцене он чёрный |
| Лак — одна блестящая поверхность, без второго слоя | с двумя слоями отражение считалось дважды, царапины оставались под гладким слоем |
| Кнопка срабатывает при отпускании на месте | ведение с кнопки — поворот вещи, запись не должна меняться |

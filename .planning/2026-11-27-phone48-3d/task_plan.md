## Decisions Made
| Решение | Причина |
|---|---|
| Форма P1-A1 (Samsung Star) | выбор автора 27.11 |
| Референс автора Nexus One отклонён как форма | вышел 01.2010, дело — 10.2009 (запрет 1) |
| Пятна на месте цифр PIN не рисовать | подсказка кода (PIN — мягкая задержка E22) |
| Ярлык бюро на телефоне — отдельным вопросом автору | новая деталь; у ноутбука ART-64 |
| Накладка камеры — по фото GEN20 (9,6 × 25,2 мм) | генератор взял длину с образца, не с ортовида |
| Узор спинки — рисунком модели, не с фото | у генератора сетка плывёт |
| Отпечатки на экране в цвет не идут | PIN — мягкая задержка, пятно = подсказка |

## Errors Encountered
| Error | Attempt | Resolution |
|---|---|---|
| kie_batch: «кредитов не хватает», баланс пуст | 1 | в процессе приложения старый KIE_API_KEY; перед запуском взять ключ из переменных учётной записи |
| Сервер отдал папку ноутбука | 1 | `python -m http.server --directory <папка>` вместо `cd` |
| Перед лёг со сдвигом 6 мм | 2 | в рамку фото попала тень; высота рамки — из ширины по пропорции ортовида |
| M1_gloss — копия фото-образца | 1 | плитка из потёртостей T1 (экран), без новой генерации |

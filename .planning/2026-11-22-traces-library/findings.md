## Technical Decisions
| Decision | Rationale |
|----------|-----------|
| Playwright берётся из game/node_modules (.pnpm, 1.65), браузеры уже стоят | не ставить второй экземпляр |
| Python-пакеты — `pip install --user`; запуск `python -P -E` (не `-I`: -I прячет user site) | -P тоже не подмешивает текущую папку в импорт |
| Вёрстка рендерится слоями: print / cole / miller + рамки [data-keep] | почерк дрожит и мажет отдельно; печатный текст не трогается |
| Шрифты рукописей — Google Fonts по ссылке в вёрстке (Marck Script — Коул, Neucha — Миллер) | ничего не скачивать в репо |
| Слой библиотеки: RGB 8 бит, бумага = 200, множитель = v/200 | блик светлее бумаги помещается (до ×1.275) |
| Проверка читаемости: линейная яркость (WCAG), ядро штриха, «до» = вёрстка с почерком на белом | меряет только то, что сделали следы и профиль |
| Профиль акта 11 — скан бюро, не ксерокс | в WEAR.md 11 — оригинал (О) |
| Строка пакета «Документация объекта, пачка «техническая» (лист приобщён отдельно)» на лист не выносится | это описание места в деле, не текст бланка |
| Шапка «VAULTLINE» — простая надпись-заглушка | раздел 16 (знаки) не решён |

## Issues Encountered
| Issue | Resolution |
|-------|------------|
| `python -I` не видит numpy (user site) | `-P -E` |
| str hash() случаен между запусками | zlib.crc32 для зерна |
| Контраст считался по маске до дрожания почерка | маски «до» и «после» раздельно |
